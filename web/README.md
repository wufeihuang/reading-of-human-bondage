# 网页版说明

`site/` 里的页面由 `build.py` 生成，**不要手改**。改内容只改 Markdown，然后重新构建。

```bash
python3 build.py
```

产出（全部单文件，CSS/JS 内联，可离线双击打开）：

| 文件 | 内容 |
|---|---|
| `site/index.html` | 总览 + 122 章地图 |
| `site/chNN.html` | 每章阅读器 |
| `site/craft.html` | 写作技法手册（可搜索） |

## 阅读器

**布局**

- **左栏是全局导航**（所有页面都有）：总览、写作技法手册、生词本／小测、122 章列表（展开、可滚动，做过的章可点，没做的灰掉）。
- **右栏是本页目录**（章节页含 4.1 这类小节，技法页含各章）。两侧都能用顶栏按钮收起，状态会记住。
- 正文：原文（英文衬线）＋译文＋词/句＋细读/写法；本章速览（篇幅、时间、地点、在场、一句话）放在原文**读完之后**。
- 「写作练习」是独立一节（九），带文本框、字数统计和本地保存。
- 每章结构：初读三问 → 原文 → 合上书（回看初读 / 5W2H / 重读三问 / 速览）→ 逐场精读 → 语言点 → 作家示范 → 背景 → 读后自测。
- **左右分屏（可选）**：只在「逐场精读」里启用，场景区真正一分为二——左边原文、译文、词句，右边该场的「细读」「写法」；两侧各占一半，右栏跟随滚动。其他章节仍是单栏。

**显示设置**（右上 `Aa`）

译文 / 词表 / 句注 / 细读 / 写法 五个开关；左右分屏；讲解默认收起；字号加减；深浅色。设置存在浏览器本地。

- 讲解（细读／写法）**默认展开**；勾「讲解默认收起」后默认折叠。
- 「理解题参考答案」不受开关影响，始终收起。

**阅读辅助**

- 顶部细进度条；`J` / `K` 上一段下一段；点段号（①⑰…）跳转并高亮。
- 悬停虚线词看音标释义；**点一下就收进生词本**（再点移出），生词本可跳回原段。
- 人名、地名等专名会自动识别并补进该段的词表（标「人名：」「地名：」），同样可点。
- 英文段落悬停出现 ▶，浏览器 TTS 朗读。
- 「小测」在左侧栏，从本章词表自动出 8 道词义题。
- 写作区：字数统计、自动保存、复制/清空。

## 源码

| 文件 | 作用 |
|---|---|
| `web/page.html` | 页面骨架（占位符 `%%TITLE%%` 等） |
| `web/style.css` | 全部样式：排版、分屏、设置面板、章节树 |
| `web/app.js` | 交互：设置、分屏跟随、生词本、小测、打卡、朗读 |
| `build.py` | Markdown → HTML；解析场景、段落、词表、细读/写法，并生成右侧讲解栏 |


## 移动端

- 工具栏固定在**底部**，正文底部留出安全间距，不会被遮住。
- 左右两侧栏默认收起；打开后是**全屏弹层**（顶部有标题和 ×），点遮罩、× 或跳转链接关闭。
- 显示设置变成**底部弹层**，带遮罩，点外部或 Esc 关闭。
- 表格（含词表、技法表）保持自然宽度，超出屏幕时**横向滚动**，不会撑宽页面或截断。
- 触屏没有 hover，词注提示自动关闭。
